# Reyhaneh (Ray) — Portfolio

Static portfolio site: a homepage and four case study pages.

```
index.html                                  Homepage
projects/dss-visual-diary/index.html        Case study 1
projects/data-discovery/index.html          Case study 2
projects/impact-card-game/index.html        Case study 3
projects/social-impact-journey/index.html   Case study 4
assets/css/style.css                        Styles
assets/js/lightbox.js                       Enlarged image view
assets/img/<project>/                       Web-optimised images (hero.jpg, hero-card.jpg, numbered images)
```

No build step is needed — the files are plain HTML, CSS and JavaScript.
To preview locally, open `index.html` in a browser.

GitHub Pages is **not** enabled for this repository yet, so the site is not public.
